Cómo Desplegar y Compartir Esta Web

Opciones gratuitas y listas para producción

Opción 1: GitHub Pages (100% Gratis y Recomendado)

  1. Crea un repositorio en GitHub (ej: pvu-plan-f21).
  2. Sube este archivo renombrado como index.html.
  3. Ve a Settings > Pages y selecciona la rama main / root.
  4. En 1 minuto tendrás una URL pública: https://tu-usuario.github.io/pvu-plan-f21/.

Opción 2: Vercel o Netlify (Arrastrar y Soltar)

  1. Ingresa a vercel.com o netlify.com/drop.
  2. Arrastra la carpeta que contenga este archivo index.html.
  3. Obtienes un enlace SSL instantáneo listo para compartir con todo el equipo.

Opción 3: Servidor Interno / SharePoint / Teams

Como toda la aplicación está en un solo archivo con Tailwind CDN y almacenamiento local, basta con alojarlo en cualquier bucket S3, Azure Blob, servidor Nginx interno o compartir el archivo .html para que cualquiera lo abra en su navegador sin configurar servidores ni base de datos.
